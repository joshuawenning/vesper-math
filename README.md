# Vesper Math

> An illustrated adventure in mathematics

## Development

```sh
npm ci
npm run dev
```

Open [localhost:4318](http://127.0.0.1:4318).

- `npm test`: Check math, progression, saves, and content
- `npm run typecheck`: Check TypeScript
- `npm run format:check`: Check formatting; `npm run format` applies it
- `npm run build` then `npm start`: Build and preview production
