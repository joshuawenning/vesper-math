# Vesper Math

An illustrated math adventure about exploration, curiosity, and finding your footing. Learn with Elian, practice in the training ground, and carry your discoveries from one world to the next.

Built with Next.js, React, and Tailwind CSS. Progress stays in your browser; Elian’s math tutor runs on-device without an account or API key.

## Develop

Requires Node.js 20.9+.

```sh
npm ci
npm run dev
```

Open [localhost:4318](http://127.0.0.1:4318).

- `npm test` — check math, progression, saves, and content.
- `npm run typecheck` — check TypeScript.
- `npm run format:check` — check formatting; `npm run format` applies it.
- `npm run build` then `npm start` — build and preview production.
